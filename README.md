# NeuroVita
🧠🏥💚🩺 NeuroVita — Repositório oficial do banco de dados do sistema NeuroVita. Contém a estrutura e desenvolvimento da camada de dados do sistema de agendamentos clínicos, dando continuidade ao projeto NeuroSpectrum. Nesta nova etapa, o banco de dados será desenvolvido utilizando MongoDB, explorando conceitos e recursos de bancos de dados NoSQL.
